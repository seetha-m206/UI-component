Capture limits

  • Selected sanitized rendered DOM/CSS samples, not complete raw documents.
  • Network metadata only, grouped losslessly by event fields with original sequence numbers retained. Request IDs, headers, cookies, payloads and response bodies deliberately excluded. URLs lose query/hash and identifiers.
  • Capture window covers Fill and settings navigation through Performance. Later DOM samples are not all covered by that network window.
  • Network requests may be background activity. No per-action causal attribution or server contract is inferred. Two aborted fetches cannot be assigned a cause from these fields.
  • No provider JavaScript function source, handler implementation, API payload schema or save outcome recovered.
  • Inventory reported 250 scripts, zero exportable stylesheet assets. DOM separately exposed one inline style and one stylesheet link. These are distinct inventory methods, not proof of missing CSS.
  • Durable screenshot files remain unavailable through the examined export surfaces. Screenshots remain session-only.
  • Performance sample matched no requested control labels and was omitted. Forms and Versions samples cover the global toolbar only.
