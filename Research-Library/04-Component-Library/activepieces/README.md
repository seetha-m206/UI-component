# Activepieces Cloud component research

Authenticated read-only observation completed on 2026-10-08 for Centilio Loop.

## Evidence boundary

- Provider navigation and passive states were observed without mutating Activepieces or a connected service.
- Account identity, email, platform and project identifiers, endpoint values, worker addresses, live timestamps and provider screenshots are excluded.
- Every screenshot path points to a fictional local fixture.
- Flow, table, agent and approval execution remain open where the empty account could not expose them safely.

## Open boundaries

- Editable flow mapping, tests, errors and publication require a safe pre-existing provider fixture. Trigger, action, approval and router topology were observed only in a disabled template canvas.
- Table schema and records require a safe pre-existing provider fixture.
- Human approval request, approve, reject, timeout and resume states require a connected sandbox.
- Provider persistence, connected-app consequences and consequential MCP permission changes remain unverified.
