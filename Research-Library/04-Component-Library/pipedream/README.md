# Pipedream authenticated component catalogue

This directory contains 48 evidence-bounded records from authenticated, read-only Pipedream and Pipedream Connect observation on 2026-10-08.

## Coverage

- Main application shell, project catalogue, empty project workspace and create-menu transient
- Project File Store and project-variable states
- Sources, connected accounts, OAuth clients and data stores
- Event History filters and plan boundary
- Project access and settings dialogs, global command search and String AI builder
- User account security, application preferences and experimental features
- Workspace settings, authentication, environment variables, domains, networking and billing or usage
- Pipedream Connect shell, onboarding, project configuration, users, webhooks, API clients and networking
- Connect global users, accounts, triggers, logs, configuration picker, command center and selectors
- Connect workspace general, team, API clients, OAuth app configs, networking, sign-in, billing and account security

## Boundaries

- Provider observations and fictional local reconstructions are not interchangeable.
- Workspace identity, user identity, email addresses, project IDs, invite links, API values, secrets, tokens and opaque request data are omitted.
- No provider resource was created, connected, saved, uploaded, invited, purchased, deleted, executed or deployed.
- Workflow builder, actions, code steps, testing, execution traces, errors, retries and version history remain **NOT OBSERVED** because the authenticated workspace was empty and reaching those surfaces would require provider state.
