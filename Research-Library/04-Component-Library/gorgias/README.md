# Gorgias component research

## Evidence boundary

- **OBSERVATION:** Seventeen reusable Gorgias screens or independent action states were inspected in an authenticated workspace on 2026-10-08.
- **RECONSTRUCTION:** Every preview is fictional and local. Workspace identity, user identity, ticket content, email addresses, phone numbers, object IDs, dates, business hours, timezone and request payloads are omitted or replaced.
- **NOT OBSERVED:** Ticket creation or content, sending, assignment, closure, archive, snooze, spam, trash, view changes, rule execution, macro execution, integration installation, channel creation, AI prompt or setup, exports, billing, access, API credentials and security changes.
- **NEEDS VERIFICATION:** Populated queues, ticket detail, provider persistence, responsive provider layouts, permissions, entitlements, exports and recurring analytics behavior.
