# Apollo component catalogue

Authenticated, read-only Apollo research for the Centilio Pulse lane.

## Evidence boundary

- **OBSERVED:** Apollo Home, People, Companies, all safely accessible top-level product screens and 37 passive settings screens on 2026-10-09, including reversible overlays, navigation, filter catalogues, tables, empty states, plan gates, analytics zero states, settings directories and default configuration views.
- **RECONSTRUCTION:** Every local preview uses fictional identity, workspace, credits, tasks and content. Local controls never contact Apollo.
- **NOT OBSERVED:** Search results, AI output, live prospect or company records, provider persistence, enrichment execution, sequence sending, inbox or calendar connection, website installation, messages, calls, deal or task creation, workflow execution, settings writes, billing submission, purchase, deletion and consequential error responses.
- **NEEDS VERIFICATION:** Network request classes, API schemas, entitlements, persistence, server validation, keyboard focus return and responsive provider behavior.

Provider screenshots and private account data are not retained. No provider-changing action was exercised.
