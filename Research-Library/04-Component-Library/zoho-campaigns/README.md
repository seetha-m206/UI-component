## Evidence boundary

- **OBSERVATION:** Authenticated read-only Zoho Campaigns observation on 2026-10-09.
- **RECONSTRUCTION:** Local previews use fictional identities, organizations, campaigns, contacts, dates and counts.
- **NOT OBSERVED:** No campaign, message, workflow, form, contact, import, upload, integration, AI prompt, setting, billing, purchase or delete action was executed.
- **NEEDS VERIFICATION:** Provider persistence, errors, permissions, responsive behavior and consequential outcomes.
