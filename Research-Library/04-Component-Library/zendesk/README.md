## Lesson

**OBSERVATION:** Pointer activation through the browser tool did not reliably expand some provider comboboxes. Re-observation and keyboard Space exposed their actual menus without modifying values.

**RECOMMENDATION:** Verify the changed UI state after each action, prefer keyboard semantics when pointer automation fails, and leave save/submit outcomes unverified until explicitly exercised.
