# PandaDoc component catalogue

Authenticated, read-only PandaDoc research for the Centilio Sign lane.

## Evidence boundary

- **OBSERVED:** The authenticated dashboard, safe document and template routes, imported-contract entry, content library, forms, template gallery and preview, contacts, catalog, reports, passive settings and one preloaded signature-block editor sample on 2026-10-09.
- **RECONSTRUCTION:** Every local preview uses fictional identity, organizations, documents, contacts, products, prices and status values. Local controls never contact PandaDoc.
- **NOT OBSERVED:** Upload, file conversion, document or template creation, recipient addition, send, signature capture, audit certificate, delivery, publishing, form responses, export, connection, API credentials, save, provider persistence, purchase, cancellation, deletion and consequential error responses.
- **NEEDS VERIFICATION:** Network request classes, API schemas, populated document histories, audit certificates, permissions, entitlements, server validation, responsive provider behavior and keyboard focus return.

Provider screenshots and account data are not retained. No provider-changing action was exercised.
