# Zapier component research

## Scope

This lane records authenticated, observation-only Zapier UX evidence for Centilio Loop. It combines current authenticated UI observations with explicitly labelled review of official Zapier documentation where deeper workflow stages would require app connections, live data, testing or provider writes.

## Evidence boundaries

- **OBSERVED:** Ten authenticated surfaces plus fifteen additional safe component states were inspected on 2026-10-08.
- **SOURCE REVIEWED:** Mapping, action testing, Paths, approvals, limits and failure semantics come from linked official Zapier help articles.
- **RECONSTRUCTION:** Every published screenshot and interactive preview is a fictional local fixture.
- **NOT OBSERVED:** No external app was connected, no account data was retained, no AI prompt or note was submitted, no field was mapped, no test or replay was run, no template or recommendation state was changed, and no Zap was published or activated.
- **NEEDS VERIFICATION:** Provider persistence, entitlement variants, connected-app consequences, role variants and responsive behavior remain open.

## Privacy and safety

Account names, email addresses, numeric account IDs, query identifiers, connection names, connected-account identities, customer data, billing values, security configuration and audit events are excluded. The live editor opened an untitled sandbox draft at the Zap creation boundary. It was not configured, tested, published, activated or deleted.

## Records

- `zapier-application-shell` — Persistent navigation, global search, product entry points and trial-aware account utilities.
- `zapier-home-copilot` — AI-assisted automation prompt, accuracy warning and start-from-scratch product choices.
- `zapier-automations-workspace` — Empty Zap inventory with filters, saved-view controls, asset navigation and recommendations.
- `zapier-creation-menu` — Cross-product creation launcher for automations, data, forms, canvases, chatbots, agents and MCP.
- `zapier-guided-templates` — Reusable automation-template explanation with a documentation boundary.
- `zapier-zap-editor-canvas` — Draft-labelled automation canvas with Copilot, trigger, action, status and version controls.
- `zapier-trigger-action-picker` — Role-aware app picker that changes built-in tool availability between trigger and action steps.
- `zapier-ai-action-palette` — AI action catalogue with custom prompts, quick actions and product categories.
- `zapier-app-connection-boundary` — Searchable connection inventory with status, usage and access columns plus an authorization boundary.
- `zapier-data-mapping-testing` — Source-reviewed field mapping and step testing mechanics kept separate from live execution.
- `zapier-flow-controls-approvals` — Conditional routing, timing, loops, reusable subflows and human approval boundaries.
- `zapier-zap-history-failures` — Run-history filters, no-results state, Autoreplay boundary and source-reviewed failure taxonomy.
- `zapier-task-usage-plan-gates` — Task chart, plan meter, trial boundary and cross-product usage explanation.
- `zapier-settings-catalogue` — Settings information architecture for profile, notifications, security, billing, members and audit log.
- `zapier-interactive-onboarding-tour` — Embedded product tour covering triggers, actions, Copilot, Paths, AI, Interfaces and Tables.
- `zapier-template-recommendation-carousel` — Recommended automation cards with app mixes, step counts and guarded card actions.
- `zapier-ai-category-tabs` — AI action navigation for first-party AI, productivity, human review and agents.
- `zapier-human-in-loop-ai-actions` — Approval trigger plus request-approval and collect-data action choices.
- `zapier-editor-linked-assets` — Empty supporting-assets panel for Tables and Forms.
- `zapier-editor-notes` — Zap notes, step notes, character meter and AI-generation boundary.
- `zapier-editor-change-history` — Unsaved-workflow history empty state.
- `zapier-editor-run-test-panel` — Run-history and Test Zap tabs with a disabled test boundary.
- `zapier-editor-status` — Step issue summary with a no-issues state.
- `zapier-editor-advanced-settings` — Disabled per-Zap Autoreplay and error-ratio choices.
- `zapier-editor-versions` — Empty version history before publication.
- `zapier-history-status-filter` — Ten-state run-status taxonomy.
- `zapier-autoreplay-help` — Disabled Autoreplay help disclosure and per-Zap override explanation.
- `zapier-usage-empty-report` — Access-scoped task-usage report with no results.
- `zapier-connection-management-states` — Connection and app views, quick filters, status choices and add-connection boundary.
