# Zoho CRM component records

This directory contains authenticated, observation-only Zoho CRM component research. Public records use fictional fixtures only. Authenticated screenshots and narrow evidence receipts remain private under `Internal/scratch-2026-10/zoho-crm/`.

## Evidence boundaries

- **OBSERVED:** Visible in the authenticated application or its accessibility and rendered DOM surfaces.
- **RECONSTRUCTION:** Fictional local state created only to explain the reusable pattern.
- **NEEDS VERIFICATION:** Not safely exercised or not proven by the inspected surface.

## Current coverage

The current batch contains 84 component records across Home, Leads, Contacts, Accounts, Deals, Forecasts, Documents, Campaigns, Tasks, Meetings, Calls, Products, Price Books, Quotes, Sales Orders, Purchase Orders, Invoices, Vendors, Cases, Solutions, Social, Visits, Messages and Projects. It covers every module visible in the inspected CRM teamspace, but it is not a full Zoho CRM audit. Creation, import, upload, share, save, send, assignment, conversion, workflow, settings, permissions, integration and billing outcomes remain unexercised.
