# DocuSign component catalogue

Authenticated, evidence-bounded research for the Centilio Sign lane.

- 27 canonical component records
- 27 exact presentation mirrors
- Fictional local previews only
- Provider identity, account numbers, opaque identifiers, private audit values, document content, tokens and payloads are excluded

## Evidence boundary

The records distinguish **OBSERVED**, **RECONSTRUCTION**, **NOT OBSERVED** and **NEEDS VERIFICATION**. Opening one public starter template advanced the provider onboarding checklist from 0 of 4 to 1 of 4 without a save. In a later user-authorized bounded pass, two explicitly fictional PDFs were uploaded and saved as unsent drafts using reserved `example.com` recipients. Signing order and recipient-specific field assignment were observed. No envelope was sent, no template was published, no purchase occurred, and no account setting was deliberately changed.
