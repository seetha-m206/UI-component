# Salesforce Service — screen and action coverage

## Scope and evidence

**OBSERVED:** Authenticated Salesforce Lightning Service area and companion Automation, inspected through Codex CUA on M5 on 6 October 2026. This map covers every section inspected in this research lane, not every Salesforce product or entitlement. The trial does not prove the commercial edition or full Service Cloud access.

**RECONSTRUCTION:** 117 canonical component records have matching catalogue mirrors, local previews and fictional screenshots. There are 28 original components, 47 section additions, 25 screen/action additions and 17 individual controls. Picker source states remain documented with their parent composition and also have separate control records. Existing screen compositions are not counted as new components again.

**NOT OBSERVED:** No provider record, collection, configuration, message, automation or access change was saved. Blank dialogs were canceled, temporary filter drafts discarded, and the provider returned to Cases. Local form, transfer, filter, selection and ordering behavior is illustrative and does not establish Salesforce behavior.

## Action-state distinctions

| Action class | Evidence boundary | Local example behavior |
| --- | --- | --- |
| Navigate or disclose | Target heading, drawer, menu, dialog or loaded result verified | Opens the reconstructed surface where implemented |
| Cancel and close | Dialog dismissal and return state observed | Dismisses and restores modal opener focus |
| New/Clone/Rename list | Only blank or prefilled unsaved form observed | Inputs change in memory, Save shows a boundary notice |
| Add filter / filter logic | Temporary editor opened and parent Cancel discarded draft | Local Done retains a temporary draft, Cancel clears it |
| Chart setup | Type, Count and grouping options inspected without selection | Native local selects demonstrate choices, Save is guarded |
| Field or navigation reorder | Controls and current order observed, no provider reorder | Local transfer and order changes are fictional demonstrations |
| Analytics search | Case query returned three reports from an empty Favorites starting point | Searches three fictional rows, no claim about provider scope or relevance |
| Selection error | Change Owner at zero selection displayed a warning | Dismissible and reopenable local toast |
| Bulk guidance | UI stated a limit of 50 and described actions | No claim that a provider limit was enforced |
| Share/Get URL | Dialog, URL field and access notice viewed, nothing copied | Uses example.invalid, Copy Link is guarded and does not write clipboard |
| Collections and color | Current values and palette viewed, all canceled | In-memory selection, canceled color edits discarded, Save guarded |
| Save/send/run/enable/connect/export/delete | Not executed on provider | Explicit local boundary message, no provider request path |

## Capture interpretation and limitations

- **OBSERVED:** Salesforce menus can initially expose fewer entries before additional items load. Actual focus and the resulting heading were checked before counting a disclosure as successful. A click target alone is not evidence of the intended result.
- **OBSERVED:** The navigation catalogue initially showed a placeholder, then loaded objects. Analytics Action Hub likewise settled from loading to populated rows. Placeholders are not recorded as final empty states.
- **OBSERVED:** Empty Cases, Contacts, Accounts, Messaging, Knowledge, Flows and Monitor views restrict access to populated detail and row-level actions in this session. Absence in a selected view does not prove absence across the workspace.
- **RECONSTRUCTION:** Native selects, local breakpoints, reduced screen compositions and focus management are implementation choices. No pixel-exact or provider-mobile claim is made.
- **NOT OBSERVED:** Backend contracts, private application state, authorization implementation, motion timing, execution logs and durable results were not inspected.
